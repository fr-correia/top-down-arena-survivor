# Arena Survivor

Top-down 2D "arena survivor" (Vampire Survivors–style) built in Unity. Player
stands in an open arena, enemies spawn in waves and converge, player
auto-attacks or aims a weapon, kills drop XP, leveling up offers a choice of
upgrades.

## Status
Pre-Stage 1. No scripts yet — see [SESSION_PLAN.md](SESSION_PLAN.md) for the
build order, starting with player movement + camera follow.

- Unity, URP 2D
- Input System package (not legacy Input Manager)
- Physics2D for movement/collision
